# The only email is the sign-in code

The app emails a Buyer only the code for signing in. Placing an Order, approving or denying a Change request, and moving an Order between statuses do not send email. The Buyer sees that activity after signing in. Staff see it in the staff area.

## Considered options

Emailing the Buyer when an Order is placed, when a Change request is decided, or when a status changes. Rejected. Order activity stays in the app.
