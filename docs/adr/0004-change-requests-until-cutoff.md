# Change requests until the cutoff

A Buyer may have one waiting Change request on a placed Order until the Change cutoff. The request may add or remove SKUs, or change Quantities or the Pickup time, while the Order is Proposed, Reserved, or Prepared. A Worker approves or denies it before Pickup. Approval updates the Order. A waiting Change request blocks fulfillment.

## Considered options

- Leaving a placed Order unchanged by the Buyer. Rejected.
- Closing Change requests when the Order becomes Prepared. Rejected. The Change cutoff closes them.
