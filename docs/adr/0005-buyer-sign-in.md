# Buyers sign in with a code to their Square Customer email

CDA creates each Buyer as a Square Customer before that Buyer can sign in. The Buyer signs in with a code sent to that customer's email. That sign-in code is the only email this app sends. After signing in, the Buyer sees only that Buyer's Orders, including Completed and Canceled. The app does not register Buyers and does not use a password for them.

## Considered options

- Letting a business register itself in the ordering app. Rejected.
- Giving Buyers a password. Rejected.
