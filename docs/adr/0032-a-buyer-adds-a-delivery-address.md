# A Buyer adds a Delivery address

A Buyer does not choose a Delivery zip from a map. They add a Delivery address: the street, city, state, zip, and phone number. Staff open and close Delivery zips from the map. Delivery is still allowed by the zip code on that address.

## Considered options

- A Buyer selects a Delivery zip's shape when placing an Order and when a Change request moves the Delivery address. Rejected. The Buyer adds an address.
