# The manager section does not ask for a PIN

Cloudflare Access is enough to maintain Staff and to edit the Season, the Line, the Change cutoff, the Delivery charge, Buyer copy, and Delivery zip names. The first Manager sets their own PIN there. Once Access has opened the staff pages, Orders can be read with nobody acting. A PIN is required only to confirm, advance, cancel, approve, deny, or open or close a Delivery zip. The Staff log records those PIN actions only.

## Considered options

- Requiring a PIN before the manager section can be used. Rejected. The first Manager would have no way to set a PIN.
- Hiding Orders until a PIN is entered. Rejected. Access already opened the staff pages.
