# Price is fixed when a SKU is added

The Price of a SKU on an Order is fixed when that SKU is added, and the Order total is the sum of each Price times its Quantity, with no discount. An approved Change request that adds a SKU uses the Price at approval. A later catalog change does not reprice SKUs already on the Order.

## Considered options

Repricing an Order when Square's catalog price changes. Rejected.
