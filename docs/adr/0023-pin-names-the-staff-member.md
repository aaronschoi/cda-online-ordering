# A PIN names the Staff member on a computer Access opened

Cloudflare Access opens the staff pages. The person who opens them is Staff. A PIN says which Staff member is at that computer. A PIN by itself never opens the staff pages. This supersedes the Staff password in ADR 0006.

## Considered options

- A password for this app, stored for each Staff member. Rejected.
- Cloudflare Access as the only Staff sign-in, with no PIN. Rejected. A shared computer needs a way to say which Staff member is there.
- A separate Manager party who opens the pages. Rejected. That person is Staff.
