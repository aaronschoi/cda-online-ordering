# Square catalog, Keystatic for other copy

Square's catalog is the source for each Style, including its name, description, and image, each SKU, and its price. The Pickup location is the Square Location where inventory is read, and its name and address come from that Location. This app does not create or complete the Square sale. Staff review Orders here and fulfill them in Square's own app, so a later way of sending Orders to Square can replace that step. Buyer-facing copy, Line membership, Season dates, the Change cutoff duration, the Delivery charge amount and its on/off toggle, and each Delivery zip's code and name live in this repo and are edited with Keystatic. On Cloudflare that editor uses GitHub mode, because the host has no content disk to write.
