# Square catalog, Keystatic for other copy

Square's catalog is the source for each Style, SKU, and its price. This app does not create or complete the Square sale. Staff review Orders here and fulfill them in Square's own app, so a later way of sending Orders to Square can replace that step. Buyer-facing copy, Line membership, Season dates, and the Change cutoff duration live in this repo and are edited with Keystatic. On Cloudflare that editor uses GitHub mode, because the host has no content disk to write.
