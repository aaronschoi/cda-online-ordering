# The Pickup location is a Square Location

The Pickup location is the Square Location where this app reads units on hand. Buyers see its name and address from that Location. Those are not copied into Keystatic or stored on the Order. Pickup time and Delivery time use that Location's local time.

## Considered options

Editing the pickup location's name and address in Keystatic. Rejected. The place is already the Square Location used for inventory, and a second copy would drift.
